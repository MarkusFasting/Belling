# SKILL: COLLABORATION WORKFLOW

## Samarbeidsprosess steg-for-steg — Co-writing, stems, feedback, roller, konflikthåndtering

---

**Metadata:**
- **Skill-ID:** SKILL_MUSIC_collab_workflow
- **Profiler involvert:** Quincy Jones, Rick Rubin, Max Martin, Lennon, Elton John
- **Kompleksitet:** Medium
- **Estimert tid:** Kontinuerlig prosess gjennom hele prosjektet

---

## FORMÅL

Komplett samarbeidsrammeverk for musikkproduksjon med flere bidragsytere. Bygger på Jones' dirigent-lederskap, Rubins "safe space"-filosofi, Martins Cheiron-workshop-modell, Lennon-McCartney dynamikken og Elton/Taupin-partnerskapet.

---

## INPUT

- Prosjektets mål (single, EP, album, remix)
- Deltakere og deres roller/styrker
- Tidslinje og deadlines
- Sjanger og referanser
- Kommunikasjonskanaler (studio, remote, hybrid)

---

## PROSESS

### Fase 1: TEAM-SETUP & ROLLER (30–60 min)

**1.1 Definer roller klart (Jones)**
- Hvem er produsent/prosjektleder? (Jones-rollen: "The General")
- Hvem skriver melodi? Tekst? Begge?
- Hvem produserer beats/instrumentaler?
- Hvem mikser? Hvem mastrer?
- Jones: "Everyone must know their role. Overlap creates conflict."

**1.2 Etabler beslutningsstruktur**

| BESLUTNINGSTYPE | HVEM BESTEMMER |
|---|---|
| Kreativ retning (sjanger, vibe) | Produsent + artist sammen |
| Melodisk valg | Topline-skriver (Martin/Sia-rollen) |
| Sonisk valg (lyd, mix) | Produsent (Jones/Pharrell-rollen) |
| Tekstlig innhold | Tekstforfatter (Lennon/Sia-rollen) |
| Arrangement | Produsent + arrangør (Jones-rollen) |
| Final approval | Prosjektleder / artist |

**1.3 Cheiron-modellen (Martin)**
- Alle i samme rom, samtidig
- Ikke sekvensielt (først tekst, så melodi, så produksjon)
- Alt skapes parallelt og i dialog
- "The best ideas come from the collision of different perspectives in real time"

### Fase 2: CO-WRITING SESSION (2–4 timer)

**2.1 Forberedelse**
- Alle har lyttet til referanse-tracks på forhånd
- Teknisk setup er klart (DAW, mikrofoner, instrumenter)
- Konsept/brief er delt med alle deltakere
- Ingen telefoner, ingen distraksjoner (Rubin: "Sacred space")

**2.2 Rubins fasiliterings-regler**
- Skape trygghet: "No idea is too stupid to say out loud"
- Ingen kritikk under brainstorming-fasen
- Produsenten lytter først, styrer etterpå
- "My job is to make the artist feel safe enough to be vulnerable"
- Eliminate alle distraksjoner — fokus er hellig

**2.3 Arbeidsflyt under session**

Steg 1: **Friskriving (15 min).** Alle bidrar idéer fritt. Ingen filter. Beat-sketches, melodifragmenter, tekstlinjer, konseptforslag.

Steg 2: **Kurasjon (10 min).** Velg de 2–3 sterkeste idéene. Jones: "Replace the weakest four" — fjern det svakeste, behold det sterke.

Steg 3: **Utvikling (60–120 min).** Bygg videre på valgte idéer. Parallelt arbeid: Én person jobber med beat, én med melodi, én med tekst.

Steg 4: **Samling (30 min).** Sett delene sammen. Lytt som ett team. Juster.

Steg 5: **Demo-innspilling (30 min).** Kutt en rask demo mens energien er der. Sia: "Don't wait. Record now."

**2.4 Lennon-McCartney-dynamikken**
- To skrivere som utfordrer hverandre
- "Eyeball to eyeball" — direkte konfrontasjon med idéer
- Lennon: Rå, ærlig, risikovillig. McCartney: Polert, melodisk, publikumsvennlig.
- Spenningen mellom perspektiver = bedre resultat enn enighet

### Fase 3: REMOTE SAMARBEID (når fysisk session ikke er mulig)

**3.1 Stem-utveksling**

| STEM-TYPE | FORMAT | INNHOLD |
|---|---|---|
| Trommer | WAV 24-bit, 48 kHz | Kick, snare, hi-hat, perkusjon (separate eller grouped) |
| Bass | WAV 24-bit, 48 kHz | Bass-instrument isolert |
| Synther/keys | WAV 24-bit, 48 kHz | Hvert synth-element separat |
| Vokal | WAV 24-bit, 48 kHz | Lead, backing, ad-libs (separate) |
| Effekter | WAV 24-bit, 48 kHz | Risers, impacts, FX |

**3.2 Prosjektfil-deling**
- Enighet om DAW (eller eksporter som stems)
- BPM og toneart tydelig merket
- Versjonshåndtering: v1, v2, v3 (aldri overskriv)
- Mappestruktur: `/ProsjektNavn/Stems/`, `/ProsjektNavn/Mixes/`, `/ProsjektNavn/References/`

**3.3 Elton/Taupin-modellen: Asynkront samarbeid**
- Tekstforfatter sender ferdig tekst
- Komponist skriver melodi over teksten, alene
- Aldri i samme rom under skapelsen
- Fungerer når rollene er klart definert og tilliten er etablert
- "The lyrics come first. I never change Bernie's words."

### Fase 4: FEEDBACK & REVISJON (kontinuerlig)

**4.1 Feedback-regler (Rubin/Jones)**

| REGEL | BESKRIVELSE |
|---|---|
| **Spesifikk, ikke generell** | "Vokalen i vers 2, takt 3 er flat" — IKKE "vokalen er dårlig" |
| **Konstruktiv, ikke destruktiv** | "Hva om vi prøver..." — IKKE "dette funker ikke" |
| **Tidsbegrenset** | Maks 3 revisisjons-runder per element. Etter det: beslutning. |
| **Lytt først** | Lytt hele veien gjennom før du gir feedback |
| **Prioritér** | Maks 3 feedback-punkter per runde. Ikke overvelm. |

**4.2 Jones' "Mute Test" for samarbeid**
- Kan prosjektet overleve uten dette bidraget?
- IF ja → bidraget er ikke essensielt. Kutt det eller gjør det essensielt.
- IF nei → dette er kjernebidraget. Beskytt det.

**4.3 Rubins "Does it give you chills?"-test**
- Den ultimate testen for kreativt arbeid
- Hvis ingen i rommet får frysninger → noe mangler
- Hvis alle får frysninger → du er på rett spor
- Emosjonell respons trumfer teknisk perfeksjon

**4.4 Revisjonshåndtering**
- v1: Første utkast (aldri slett dette)
- v2: Etter første feedback-runde
- v3: Etter andre feedback-runde
- Final: Etter siste godkjenning
- Rubin: "Sometimes v1 is the best. Don't polish away the magic."

### Fase 5: KONFLIKTHÅNDTERING (når nødvendig)

**5.1 Kreative uenigheter**
- Lytt til begge sider uten å avbryte
- A/B-test: Lag begge versjoner, lytt sammen, la musikken avgjøre
- Jones: "The song decides. Not the ego."
- IF ingen løsning etter 30 minutter → produsenten tar avgjørelsen

**5.2 Kreditt og eierskap**
- Avtal splits FØR dere starter å skrive
- Standard co-writing: Lik deling mellom alle som var i rommet
- Martin-modellen: Alle i skrivesesjonen deler, uavhengig av bidragsstørrelse
- Dokumentér bidrag underveis (hvem skrev hva)

**5.3 Deadline-konflikter**
- Sett realistiske milepæler fra start
- Buffer: Alltid 20% ekstra tid innkalkulert
- IF deadline ryker → prioritér. Hva er essensielt? Hva kan kuttes?
- Jones: "Quality takes time. But infinite time produces nothing."

## OUTPUT

- Klart definerte roller og beslutningsstruktur
- Fungerende co-writing sessions (fysiske eller remote)
- Effektiv stem/prosjektfil-utveksling
- Konstruktiv feedback-syklus
- Ferdig produksjon med alle bidragsytere fornøyde
