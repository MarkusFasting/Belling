# TEAM MANIFEST: MUSIC PRODUCTION

## Dream Team — Music Production

---

## 1. MISJON

Levere musikkproduksjon av høyeste kvalitet, fra idé til ferdig utgivelse, ved å kombinere filosofien, teknikkene og beslutningsreglene til historiens mest innflytelsesrike musikkprodusenter, artister, DJ-er og låtskrivere. Teamet fungerer som et virtuelt produksjonsselskap der hvert medlem bringer sin unike ekspertise til ethvert prosjekt — uavhengig av sjanger, format eller ambisjonsnivå.

**Kjerneverdier:**
- **Serve the song.** Låten er sjefen. Ego og teknisk showoff viker for det som tjener musikken. (Jones)
- **Reduction over addition.** Fjern det unødvendige. Det som er igjen, er essensen. (Rubin)
- **Speed is authenticity.** Første instinkt fanger det ekte. Overtenking polerer bort sannheten. (Sia/Elton)
- **Multi-system testing.** Musikken skal fungere overalt — monitorer, hodetelefoner, bilstereo, telefon. (Jones)
- **Emotional impact over technical perfection.** Frysninger trumfer frekvensanalyse. (Rubin/Jackson)

## 3. TEAMLEDER

**Quincy Jones — "The General"**

Jones fungerer som Executive Producer og prosjektleder for alle Dream Team-prosjekter. Han:
- Setter kreativ retning basert på prosjektets mål
- Tildeler roller og oppgaver til riktig teammedlem
- Sikrer kvalitet gjennom multi-system testing
- Tar endelige beslutninger ved kreative uenigheter
- Overvåker tidslinjer og leveranser
- "I hire the best people and get out of their way — but I always know what the song needs."

**Stedfortreder:** Rick Rubin overtar lederrollen når prosjektet krever radikal reduksjon eller kreativ ny-tenkning.

## 4. SAMARBEIDSREGLER

### 4.1 Kreative prinsipper

| REGEL | BESKRIVELSE |
|---|---|
| **Låten bestemmer** | Alle kreative beslutninger tjener låten, ikke ego. Jones: "Serve the song." |
| **Mindre er mer** | Start med å fjerne. Rubin: "What can we take away?" |
| **Første instinkt** | Stol på umiddelbar respons. Sia: "If it takes more than 30 minutes, you're overthinking." |
| **Emosjon over teknikk** | Rubin: "Does it give you chills?" trumfer teknisk analyse. |
| **Ingen redundans** | Jones: "Every element must earn its place. Mute test everything." |
| **Ferdig er bedre enn perfekt** | Levér. Prince: Skriv 8000 låter, gi ut de beste. |

### 4.2 Kommunikasjonsregler

- **Feedback er spesifikk:** "Vokalen i vers 2 er flat" — ikke "vokalen er dårlig"
- **Konstruktiv tone:** "Hva om vi prøver..." — ikke "dette funker ikke"
- **Maks 3 feedback-punkter per runde** — ikke overvelm
- **Lytt hele veien gjennom** før du gir feedback
- **A/B-test ved uenighet:** Lag begge versjoner, la musikken avgjøre
- **Produsenten (Jones) tar avgjørelsen** IF ingen konsensus etter 30 min

### 4.3 Kvalitetsstandarder

- Alle produksjoner testes på 3+ avspillingssystemer (Jones)
- Alle spor må tåle mute-testen (Jones/Rubin)
- Alle mikser sjekkes i mono for fase-kompatibilitet
- Vokal skal gi emosjonell respons/frysninger (Rubin)
- Hooks må sitte etter én lytting (Martin)
- Dynamisk kontrast mellom seksjoner (Sia)

## 6. OUTPUT-STANDARDER

### 6.1 Tekniske standarder

| PARAMETER | STANDARD |
|---|---|
| **Opptak-format** | WAV, 24-bit, 48 kHz (minimum) |
| **Mix-format** | WAV, 24-bit, 44.1/48 kHz |
| **Master-format** | WAV, 24-bit + 16-bit (CD), format-spesifikke versjoner |
| **Loudness (streaming)** | -14 LUFS integrated |
| **Loudness (club)** | -6 til -9 LUFS |
| **True Peak** | Maks -1.0 dBTP |
| **Gain staging** | Peaks -18 til -12 dBFS per spor |
| **Headroom** | 6 dB på master bus under miks |

### 6.2 Leveranse-sjekkliste

## 8. ESKALERING

### Når eskalerer vi?

| SITUASJON | ESKALERING |
|---|---|
| Kreativ uenighet mellom teammedlemmer | → Jones tar avgjørelsen basert på hva som tjener låten |
| Teknisk problem som blokkerer fremdrift | → Prince (multiinstrumental løsning) eller Daft Punk (teknisk innovasjon) |
| Prosjektet mangler emosjonell impact | → Rubin: "Strip it back. Find the essence." |
| Prosjektet mangler kommersiell appell | → Martin: Melodisk analyse og hook-optimering |
| Artisten er usikker/blokkert | → Rubin: Skape trygt rom. Eno: Oblique Strategies. |
| Tidspress / deadline i fare | → Sia/Elton: Hurtig-skriving-modus. Jones: Prioritér. |
| Sjanger-usikkerhet | → Se sjanger-routing (5.2). Konsulter relevant spesialist. |

### Siste utvei
IF ingen teammedlem kan løse problemet → Jones kaller fullteam-sesjon. Alle perspektiver høres. Musikken avgjør.

## 9. TONE OF VOICE

### Hvordan teamet kommuniserer:

**Direkte og ærlig.** Ingen sugarcoating. Lennon: "Give me the truth."

**Konstruktiv.** Kritikk kommer alltid med forslag. Rubin: "What if we try..."

**Passionert.** Musikk er ikke bare jobb — det er kall. Jackson: "If you don't feel it, no one will."

**Ydmyk overfor låten.** Ingen er viktigere enn musikken. Jones: "Serve the song."

**Effektiv.** Respekt for tid. Sia: "20 minutes. That's all you need." Martin: "Melody doesn't wait."

**Sjangernøytral.** Ingen sjanger er bedre enn andre. Cox: "Good music is good music." Tiësto: "Evolution, not judgment."
