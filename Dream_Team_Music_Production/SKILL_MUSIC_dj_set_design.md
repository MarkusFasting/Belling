# SKILL: DJ SET DESIGN

## DJ-sett design steg-for-steg — Tracklist, energikurve, overganger, live-performance

---

**Metadata:**
- **Skill-ID:** SKILL_MUSIC_dj_set_design
- **Profiler involvert:** Carl Cox, Tiësto, Daft Punk, Avicii, Kraftwerk
- **Kompleksitet:** Medium–Høy
- **Estimert tid:** 2–8 timer forberedelse + live performance

---

## FORMÅL

Komplett DJ-sett design fra track-utvalg til live-performance-strategi. Bygger på Carl Cox' marathon-sett filosofi, Tiëstos crossover-tenkning, Daft Punks live-performance-innovasjon, Aviciis melodiske energikurver og Kraftwerks visuell/audiosynkronisering.

---

## INPUT

- Settets lengde (1 time, 2 timer, 4+ timer)
- Venue-type: Klubb (intimt), festival (massivt), afterparty, radio/stream
- Sjanger-fokus eller sjanger-bredde
- Tidspunkt: Opening, peak time, closing
- Publikums-profil: Kjennere, mainstream, blandet

---

## PROSESS

### Fase 1: TRACK-UTVELGELSE (60–120 min)

**1.1 Bygg track-pool (Cox)**
- Start med 3x antall tracks du trenger (2-timers sett = 60–80 tracks i pool)
- Cox: "100 records is enough, but you need to know every single one of them intimately"
- Kategoriser tracks etter energinivå (1–10)
- Kategoriser etter type: opener, builder, peak, breakdown, closer

**1.2 Kjenn dine tracks**
- For HVER track: Kjenn toneart, BPM, energinivå, emosjonell karakter
- Identifiser mix-punkter: Hvor funker intro/outro-miksing best?
- Identifiser vokale elementer, breakdowns, drops
- Kjenn 2–3 "exit-tracks" for hver track (hva passer etter denne?)

**1.3 Spesialtracks**
- 3–5 "secret weapons": Tracks ingen forventer som alltid fungerer
- 2–3 klassikere/anthems: For peak-time emosjonelle øyeblikk
- 2–3 uutgitte/eksklusive: For å differensiere settet
- 1–2 "rescue tracks": Fungerer alltid uansett stemning, for å redde energien

**1.4 Tiësto: Sjanger-bredde**
- Ikke lås deg til én sjanger — mix mellom sub-sjangre for dynamikk
- Trance → progressive → house → techno-overganger gir reise-følelse
- "Reinvent or die" — overrask publikum

**2.2 Cox' pustende bølger**
- Energien er IKKE en rett linje oppover
- "Energy flows like breathing — in and out, tension and release"
- Bygg opp 15–20 min → peak 5–10 min → la det puste ned 5–10 min → bygg igjen
- Hvert puste-punkt lar publikum hvile og gjør neste peak sterkere

**2.3 Energikurve etter sett-type**

| SETT-TYPE | ENERGIKURVE |
|---|---|
| **Opening** (1–2 timer) | Start på 3/10, bygg gradvis til 6/10. Aldri peak. |
| **Peak time** (1–2 timer) | Start på 6/10, veksle mellom 7–10/10 med puste-pauser. |
| **Closing** (1–2 timer) | Start på 7/10, gradvis ned til 3/10, siste track som avslutning. |
| **Marathon** (4+ timer) | Full kurve: 2→6→9→5→10→7→9→4. Cox-spesialitet. |
| **Festival main stage** | Start 7/10, hold 8–10 med korte dips. Anthems og drops. |

### Fase 3: OVERGANGS-DESIGN (30–60 min)

**3.1 Overgangs-typer**

| TYPE | TEKNIKK | BEST FOR |
|---|---|---|
| **Beat-match mix** | Synk BPM, blend over 16–32 takter | Standard, jevn flyt |
| **EQ-swap** | Bytt bass/mid/high gradvis mellom tracks | Sømløs overgang |
| **Filter sweep** | LP-filter ut/inn | Dramatisk, energibygg |
| **Cold cut** | Brå stopp → ny track | Overraskelse, energiboost |
| **Acapella overlay** | Vokal fra track A over instrumental B | Kreativ, unik |
| **Loop + layer** | Loop en seksjon, layer inn neste track | Kontrollert build |
| **Echo out** | Delay/echo feedback ut → ny track inn | Smooth exit |

**3.2 Toneart-kompatibilitet**
- Camelot Wheel / Circle of Fifths for harmonisk miksing
- Ideelt: Samme toneart eller relatert (±1 på Camelot)
- Akseptabelt: ±2 på Camelot med kort overgang
- Unngå: Dissonante toneart-kombinasjoner i lange blends
- Cox: "Your ears are the best key detector. IF it clashes, move on."

**3.3 BPM-management**
- Gradvis BPM-økning: +1–2 BPM per overgang for energibygging
- Brå BPM-hopp: Bruk cold cut eller breakdown for å skifte tempo
- Avicii-teknikk: Half-time breakdown i raskere sett for kontrast
- Aldri mer enn ±5 BPM mellom to tracks i en blend

### Fase 4: SETT-ARKITEKTUR (30–60 min)

**4.1 Intro-design (første 15–30 min)**
- Start med atmosfærisk/ambient element (Eno-inspirert)
- Introdusér beat gradvis
- Etabler groove og energinivå
- Ikke spill anthems tidlig — spar de beste kortene

**4.2 Journey-design (Avicii/Tiësto)**
- Settet skal fortelle en historie med begynnelse, midte og slutt
- Emosjonelle vendepunkter: Når byttes stemningen?
- Melodiske øyeblikk: Vokal-tracks som ankerpunkter i settet
- Avicii: Melodiske drops som emosjonelle klimaks
- Tiësto: Sjangerbytte som narrativt virkemiddel

**4.3 Peak-time strategi**
- Spar de sterkeste tracks til peak-time
- 2–3 tracks i sekvens med eskalerende energi
- Breakdown → build → drop → breakdown → bigger build → bigger drop
- Cox: "Read the crowd. The floor tells you when they're ready for the peak."

**4.4 Closing-strategi**
- Gradvis nedtrapping av energi over 15–30 minutter
- Siste 2–3 tracks: emosjonelle, melodiske, memorable
- Avslutt med en track som definerer settet
- Kraftwerk: La siste lyden henge i luften

### Fase 5: LIVE-PERFORMANCE (under settet)

**5.1 Les publikum (Cox)**
- Overvåk dansegulvet konstant
- Hendene i lufta = energien er riktig
- Folk som stopper opp = tid for å justere
- IF energien faller → "rescue track"
- IF energien er maksimal → hold den, ikke eskalér mer

**5.2 Improvisasjon vs. plan**
- Cox: "Never pre-plan a set. Have your records, know them, but let the crowd decide."
- Ha en grov plan men vær villig til å avvike 50%+
- Nøkkelmomentene (peaks, closing track) kan planlegges
- Alt mellom er fleksibelt basert på publikumsrespons

**5.3 Tekniske virkemidler**
- Effekter: Bruk delay, reverb, filter sparsomt men effektivt
- Looping: Loop en seksjon for å forlenge et øyeblikk
- Daft Punk: Live remixing — omstrukturér tracks i sanntid
- Acapella-spill: Vokal over instrumental for unike mashups

---

## OUTPUT

- Track-pool med 50–100 tracks, kategorisert etter energi/type/toneart
- Energikurve-plan (visuell diagram)
- Grov sett-arkitektur med nøkkelmomentene planlagt
- 2–3 alternative stier for ulike publikumsresponser
- Ferdig DJ-sett (live eller innspilt)

## EKSEMPEL

**Oppgave:** Design et 2-timers peak-time techno/house-sett for nattklubb (200 pers).

**Prosess:**
1. Track-pool: 70 tracks, kategorisert: 20 tech-house, 25 techno, 15 melodisk techno, 10 peak-time bombs
2. Energikurve: Start 6/10 → bygg til 8/10 (30 min) → pust til 6/10 (10 min) → bygg til 9/10 (20 min) → pust til 7/10 (10 min) → finale-peak 10/10 (20 min) → wind down til 5/10 (30 min)
3. Overganger: Primært EQ-swap og beat-match (16–32 takter). Cold cuts for dramatiske øyeblikk.
4. Intro: Groovy tech-house, 122 BPM, gradvis mørkere
5. Peak 1 (30 min): Driving techno, 126 BPM, vokal-hooks
6. Pust (10 min): Melodisk techno, breakdown-fokus
7. Peak 2 (20 min): Peak-time techno, 128 BPM, anthems
8. Closing (30 min): Emosjonell techno → melodisk house → siste track: klassiker som avsender alle hjem med et smil
